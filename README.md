Trabajos Prácticos — Métodos Numéricos

Repositorio con los trabajos prácticos desarrollados durante la cursada de la materia Métodos Numéricos.
Incluye implementaciones y análisis de distintos algoritmos numéricos utilizados para la resolución aproximada de problemas matemáticos y computacionales.

Contenidos
Métodos de búsqueda de raíces
Resolución de sistemas de ecuaciones lineales
Interpolación y ajuste de curvas
Integración y derivación numérica
Métodos iterativos
Análisis de error y convergencia
Visualización y análisis de resultados
Tecnologías utilizadas
Python
NumPy
Matplotlib
Jupyter Notebook
Objetivo

Aplicar conceptos teóricos de análisis numérico mediante implementaciones prácticas, evaluando precisión, estabilidad y eficiencia computacional de los distintos métodos.
